# 调研问题提纲

准备询问以下问题。可根据对方的实际经历追问，不引导对方认可我们已经选定的参数。

1. 现在通常怎样安排投喂和清洁？最麻烦的环节是什么？
2. 如果使用自动设备，希望怎样判断需要补粮，怎样避免连续出粮？
3. 哪些位置允许进行课程演示？附近是否有合适的电源、空间和固定条件？
4. 设备异常时，操作者希望怎样停止、检查和恢复？
5. 平时由谁补粮、清洁和检查卡粮？对操作有什么要求？

这份提纲还没有访谈答案。现场记录时把对方说的情况、自己看到的事实和个人判断分开写。对于器材，第一周先列出后面要确认的事项：型号是否与方案一致，接线资料是否齐全，是否具备单模块测试条件；称重标定、舵机动作和整机出粮留到后续实测阶段。
