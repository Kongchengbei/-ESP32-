# 现场调研计划

在设计具体使用流程前，需要先了解设备能放在哪里、谁会操作，以及现场有哪些限制。第一周先准备调查内容，不把现有方案中的设想当成已经得到的用户意见。

计划先向老师确认课程演示的范围和场地，再联系愿意接受询问的管理人员或照护人员。谈话前说明用途，征得同意后做简短记录，不要求对方提供姓名、联系方式等无关信息。拍设备和安装位置时尽量避开路人。

观察时重点看电源、空间、固定方式、通行和后续清洁维护条件。没有实际量过的尺寸或电压不填数字，没有见到的动物活动不写结论。下一周在许可和条件具备后开展，条件不足就记录没有开展的原因。

整理出的意见交给赵振翔判断是否需要补充需求，涉及接口和接线的问题与曾崇豪确认。原始记录实际产生后再交赵若辰登记，本周先提交这份计划和问题提纲。
