# 项目志愿与启动讨论

我们拟选的方向是校园流浪动物自动投喂系统，先做实验室桌面原型。系统尝试根据猫类别识别结果和食盆余粮控制挡门，让投喂过程可以演示、记录和检查。

现有资料已经提供方案、ESP32工程和实验说明，可用于开始阅读。实际器材是否齐全、哪里可以开展观察、用户希望如何操作，都还需要确认。选择这个项目主要是因为五个人能分别承担需求、实现、仿真、文档和实测，也能在八周内分阶段推进。

启动讨论需要确认项目名称与题库来源、五人组队审批、成员分工和可投入时间，再商量每周短会、提交时间及下一周安排。会议真实开展后，把时间、参会人和决定补进记录；这里只先列讨论内容，不代写已发生的会议。

下一周准备由赵振翔细化需求，曾崇豪配置开发环境，刘营鑫继续整理仿真条件，杜若熙确认调研许可，赵若辰汇总讨论结果和资料。具体期限由小组确定。
