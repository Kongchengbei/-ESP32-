# 团队章程草案

项目暂定为基于ESP32与边缘视觉的校园流浪动物自动投喂桌面原型。赵振翔负责需求和驱动测试，曾崇豪负责固件和接口，刘营鑫负责仿真及电脑端AI实验，赵若辰负责文档和版本记录，杜若熙负责调研和实物测试。

每人维护自己的附件目录。需要改动公共需求、接口或者进度安排时，先在小组里说明原因，讨论后再更新。程序有问题时把触发条件和现象记下来，交给对应负责人处理；修好后保留复测记录。

建议每周安排一次短会，说清已经完成的内容、没有解决的问题和下周任务。具体时间与联系方式等成员确认后补充。不能参加时提前告知，并在会后查看记录、补充自己的意见。出现分歧先看依据，讨论后仍无法决定的再请老师帮助判断。

GitHub采用个人分支提交，由组长查看PR后合并。原始数据和失败记录保留，引用已有代码时写明来源。五人组队的审批状态按课程组实际回复填写，目前不预写批准结果。
