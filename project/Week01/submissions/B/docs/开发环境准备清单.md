# 开发环境准备清单

现有工程使用Arduino开发ESP32，README指定ESP32 core 3.3.12，目标板为ESP32 Dev Module。HUSKYLENS库随工程提供，不需要再随意安装另一份同名库。

第二周配置环境时需要确认Arduino IDE或CLI的版本、ESP32 core版本、目标板设置和工程路径。先编译主程序，再考虑真实板卡的连接与烧录。电脑能编译不代表模块已经能正常工作，烧录端口也要等连接实物后确认。

第一周先确认手头是否有开发电脑、能否安装软件，以及是否拿到完整工程。个人电脑上是否已经安装、是否编译成功，按实际情况补充，不预填结果。遇到无法配置的地方先查官方说明或询问AI，再把没有解决的问题带到小组讨论。
