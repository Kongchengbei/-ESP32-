# 仿真范围与台架边界

第一周先确定仿真要回答什么问题。我们希望先在电脑上检查投喂判断和状态变化，减少后面直接连接实物时排查程序的难度。仿真接收的是整理后的识别结果、重量、按钮事件和时间变化，输出应能看出是否允许投喂、是否关门以及是否进入故障状态。

初步考虑正常投喂、目标不匹配、余粮充足和模块异常这几类情况。输入和预期写在仿真问题清单中，第二周再根据赵振翔整理的需求补齐，第三周开始实现和运行模拟器。第一周不提交模拟器，也不填写仿真运行结果。

有些问题只能等实物验证，例如传感器读数抖动、供电是否稳定、舵机能否带动挡门、真实粮食是否顺利落下。即使电脑上的逻辑走通，也不能据此认定这些问题已经解决。

电脑端AI实验是后面单独开展的学习任务。第一周只记住它和HUSKYLENS内置识别的区别，数据准备、训练和评估按后续周次安排。
