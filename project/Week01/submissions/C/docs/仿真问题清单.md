# 仿真问题清单

先用四个常见情况讨论输入和期望，暂不展开完整边界表。

|情况|准备给程序什么输入|希望看到的行为|
|---|---|---|
|正常投喂|已布防，识别确认成立，余粮不足，其余条件正常|进入受限投喂流程，之后检查重量变化|
|目标不匹配|收到与配置类别不一致的识别结果|不因这次识别开门|
|余粮充足|识别符合要求，但食盆已有足够粮食|不继续出粮|
|模块异常|读取识别或重量时出现异常|停止新的投喂，按程序规定处理故障|

这些都是待实现的场景，不是测试结果。第二周与赵振翔核对每个场景的具体条件，与曾崇豪确认状态和输入的表示方式。尤其要确认“识别成立”需要哪些条件，避免在仿真中把关键步骤省掉。
